\section{\texorpdfstring{\textbf{Appendix C. Dataset/resource and readiness card}}{Appendix C. Dataset/resource and readiness card}}\label{appendix-c.-datasetresource-and-readiness-card}\label{app:c}

\subsection{\texorpdfstring{\textbf{Purpose}}{Purpose}}\label{purpose}

\hyperref[app:c]{Appendix C} should record the dataset-level and asset-level resources used or ruled out in an episode. It answers whether a conceptually suitable dataset was actually reachable, authorized, complete enough, and compatible with the selected workflow. It documents dataset identity, access class, BIDS and derivative roots, phenotype and covariate availability, target variables, feature assets, missing resources, backend reachability, readiness verdicts, blockers, and non-executable candidates.
