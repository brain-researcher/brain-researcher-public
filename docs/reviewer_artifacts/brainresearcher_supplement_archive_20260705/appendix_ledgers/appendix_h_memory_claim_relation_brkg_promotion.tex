\section{\texorpdfstring{\textbf{Appendix H. Memory card, claim-relation events, and BR-KG promotion status}}{Appendix H. Memory card, claim-relation events, and BR-KG promotion status}}\label{appendix-h.-memory-card-claim-relation-events-and-br-kg-promotion-status}\label{app:h}

\hyperref[app:h]{Appendix H} is the memory-writeback ledger: it records which reviewed claims become memory cards, which do not, how new claims relate to prior memory, and whether a BR-KG promotion path exists. The memory workflow is summarized in Supplementary Fig.~\ref{fig:field-memory}.

\subsection{\texorpdfstring{\textbf{H1. Purpose and scope}}{H1. Purpose and scope}}\label{h1.-purpose-and-scope}

This card records reviewed claims and their relation to prior memory. It stores accepted, qualified, rejected, blocked, and speculative outcomes separately so readers can see what enters accepted memory, what remains only in the run bundle, and what may later become a candidate BR-KG update.
