\section{\texorpdfstring{\textbf{Appendix F. Execution trace, artifact manifest, and provenance card}}{Appendix F. Execution trace, artifact manifest, and provenance card}}\label{appendix-f.-execution-trace-artifact-manifest-and-provenance-card}\label{app:f}

\hyperref[app:f]{Appendix F} is the execution evidence ledger: it proves what actually ran, where it ran, what artifacts were expected and produced, and whether failures, retries, checksums, and environment versions were recorded.

\subsection{\texorpdfstring{\textbf{F1. Purpose and scope}}{F1. Purpose and scope}}\label{f1.-purpose-and-scope}

This card records the authoritative execution provenance for an episode. It stores the run bundle, event trace, trajectory document, observation record, analysis bundle, artifact manifest, logs, checksums, backend and software versions, preflight results, failures, retries, recovery events, and final execution status. Scientific interpretation and claim eligibility are handled in \hyperref[app:g]{Appendix G}.
