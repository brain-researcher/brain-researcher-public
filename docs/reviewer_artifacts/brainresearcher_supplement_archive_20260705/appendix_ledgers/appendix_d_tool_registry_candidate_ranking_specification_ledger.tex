\section{\texorpdfstring{\textbf{Appendix D. Tool registry, candidate ranking, and specification ledger card}}{Appendix D. Tool registry, candidate ranking, and specification ledger card}}\label{appendix-d.-tool-registry-candidate-ranking-and-specification-ledger-card}\label{app:d}

\hyperref[app:d]{Appendix D} is the tool-registry ledger: it proves how Brain Researcher moved from a scientific intent to candidate tool families, ranked candidates, rejected alternatives, selected canonical tool/\allowbreak{}workflow IDs, and generated backend-specific recipes.

\subsection{\texorpdfstring{\textbf{D1. Purpose and scope}}{D1. Purpose and scope}}\label{d1.-purpose-and-scope}

This card records how Brain Researcher selected, ranked, rejected, and resolved candidate tools and workflows during an episode. It links the episode intent and resource ledger to the typed tool registry, family cards, canonical tool IDs, parameter schemas, compatibility checks, backend recipes, and rejected-candidate ledger.
