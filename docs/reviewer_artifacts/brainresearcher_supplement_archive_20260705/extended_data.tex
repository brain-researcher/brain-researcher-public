\noindent This document reproduces, in full, the data-card ledgers, the per-rule
scientific-review registry, and the benchmark item/example/bundle manifests that
were moved out of the lean reviewer-facing Supplementary Information to keep it
short. The Supplementary Information retains a one-paragraph data card for each
appendix (Appendix~A--J) and the reviewer-facing Appendices~G, I, J, and~K; this
Extended Data document carries the corresponding full ledgers. Appendix and
section labels match the Supplementary Information. See \texttt{supplement\_crosswalk.md}
and \texttt{MANIFEST.json} in this package for the mapping and checksums.
